# sdl.space

Static Astro site for [sdl.space](https://sdl.space) — premium domain acquisition landing page.

## Stack

- **Astro** (static output, no adapter)
- **TypeScript** + **Tailwind CSS**
- **Content Collections** for pillars, use cases, and market stats
- **Cloudflare Workers Static Assets** (assets-only deploy)
- **Cloudflare Images CDN** for hero/OG imagery

## Development

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
npm run deploy   # build + wrangler deploy
```
